# 🛸 天空之城 · 空中浮岛竞速经营

一款以**云海浮岛竞速**为核心玩法的经营模拟游戏。玩家经营一支空中竞速车队，在漂浮于云海的浮岛赛道上逐站参赛，赢取积分与奖金，改装飞艇、招募机师技工、达成赞助目标，向赛季之巅发起冲击。

## 快速开始

```bash
npm install     # 安装依赖
npm run dev     # 启动开发服务（server:4180 + vite:5204）
```

浏览器访问 **http://localhost:5204** 即可开始游戏。

> 若 5204 端口被占用，Vite 会自动切换到其他端口；后端 API 代理随之生效，无需手动修改。

## 技术栈

| 层 | 技术 |
|----|------|
| 前端 | Vue 3（`<script setup>`）+ Vite + Pinia |
| 后端 | Express + Node.js 内置 `node:sqlite` |
| 数据库 | SQLite（`server/sky.db`，首次启动自动建表并写入演示数据） |

## 玩法说明

1. **云海航线图**：主场景为云海浮岛赛季航线图，6 座浮岛依次排列。点击浮岛上的 **🚀 开赛** 进入分站竞速。
2. **分段分站竞速**：每站分 **启航段 / 中段云流 / 冲线段** 三段。6 艘飞艇（玩家 + 5 名对手）按各自分段用时推进，右侧 LIVE 榜实时刷新名次；每段发挥都受 **天气、已装备改装、部件健康、机师/技工状态** 共同影响，赛道上会弹出超车与天气事件横幅。
3. **中断续看**：开赛瞬间服务器即生成并落库一份完整比赛记录，动画只播不结算。中途退出或刷新页面后，航线图出现「比赛进行中 · 点击中断续看」浮条，赛站按钮变为 **▶ 续看**，从上次观赛进度继续。
4. **一次结算，杜绝重复**：比赛播完（或点「跳过动画直接结算」）才按该记录发放积分/奖金/磨损/声望与人员经验；结算接口幂等，断线重放、重复点击都不会重复发奖。
5. **历史回放**：赛季之巅抽屉的每场战绩都可 **↻ 回放**，用同一份记录重放全场动画与排名，回放只展示结果、绝不再次结算。被历史修复作废（status=void）的越站记录不会出现在历史战绩中，也不能再结算。
6. **赛季推进**：每站完赛进度条 +1，6 站全部完赛为一季；各岛天气与难度不同（晴/风/雨/雾/雷暴，难度 ★1-★5）。
7. **机库**：查看飞艇四项性能（速度/转向/加速/耐久）与部件健康度；装备/卸下改装件（引擎/翼板/氮气/龙骨/护甲）；招募机师与技工；部件磨损可花费维护恢复至 100%。
8. **飞艇租赁**：赛前可在机库签约租用不同性能的高阶飞艇——签约即按租约扣 **押金 + 租金**（租金不退）；租约期间车队以租赁艇出赛，**比赛磨损记入租约**（自有艇封存不磨损），归还时按「累计磨损 × 费率」从押金中结算退款；租约场次用尽须先归还才能继续参赛，归还结算幂等、不会重复退款。
9. **赛季之巅**：赛季积分达标可解锁赞助商奖励（资金 + 声望），并回放本赛季各站比赛。

## 竞速记录与结算引擎（单一事实来源）

- 开赛后一条 `races` 记录落库，内含三段全部赛艇的分段 pace/用时/入场时间、天气与发挥系数、**改装件快照**、**机师/技工状态快照**、分段事件（超车/天气）以及**预先确定的最终名次与奖励**。
- 动画、LIVE 实时排名、结算卡、历史回放**全部从同一份记录派生**，不存在各算各的导致「画面名次」与「结算名次」不一致的问题。
- 分段 pace：性能四项按段加权合成（启航拼加速、中段拼极速转向、冲线拼极速爆发），再乘 **部件健康系数**（地板 0.62）与 **分段天气系数**（雾/雷暴在中段、冲线段压制更大）；机师胆识提供天气抗性，机师带队加成与技工调校加成作为常数项叠加。
- 对手 AI 同口径计算天气抗性与机师/技工加成，并按赛站难度与随机档位拉开快慢差距：低难度多为教学局，高难度需靠改装与维护争胜。
- 名次 1-6 对应 F1 式积分（25/18/15/12/10/8）+ 名次奖金；赛后部件按赛道难度与天气磨损，机师经验/心情随之变化。
- 结算走数据库事务并以 `races.settled` 为唯一闸门（事务内二次校验，同步执行下并发重放也只发一次奖），重复请求直接返回同一份结果（幂等）；越站/作废记录（status=void）返回 409，赞助商在同一事务内按积分对账。
- **越站历史修复（启动迁移补偿）**：首个未完成赛站之后的完赛记录一律视为越站，在同一事务内按各场发奖口径回滚积分/奖金/声望、**部件磨损（parts_dur/hp）与机师经验/心情**；磨损归属一律以开赛快照为准——在履租约回滚租约磨损/场次（不动钱），**已归还租约则剔除该场磨损后重算磨损费并补退押金差额**（回写租约行，绝不误扣封存的自有艇），随后删除流水、把记录置为 void 并重置赛站，最后重算赞助对账与赛季名次；修复本身幂等，重启重复执行不会二次回滚或二次补退。

## 比赛相关接口

| 方法与路径 | 说明 |
|-----------|------|
| `GET /api/shop` | 零件商品目录（名称/槽位/加成项/数值/价格均为服务端配置） |
| `POST /api/shop` | 购买零件；**请求体只接受商品 `id`**。价格、属性与加成由服务端按目录核定，客户端提交的 `price/bonus/stat/slot/name` 一律忽略；编号非法返回 400，扣款与入库在同一事务内完成 |
| `GET /api/rentals` | 租赁艇型目录 + 当前租约 + 最近归还记录（性能/押金/租金/场次/费率均为服务端配置） |
| `POST /api/rentals/rent` | 签约租艇；**请求体只接受艇型 `id`**。费用与性能由服务端按目录核定；同一事务内校验「无在履租约 → 资金 → 扣押金+租金 → 建约」，已有租约或比赛进行中返回 409 |
| `POST /api/rentals/return` | 归还结算：磨损费 = 累计磨损 × 费率，退款 = 押金 − 磨损费（下限 0）；以 `status='active'` 为唯一闸门，幂等，重复请求返回同一份结果、绝不二次退款；比赛进行中返回 409 |
| `POST /api/races/start/:cid` | 开赛并生成完整比赛记录；该站已有 running 记录时返回同一份（续看）；租约场次用尽时拒绝开赛，须先归还租艇 |
| `GET /api/races/:id` | 读取单场比赛记录 |
| `POST /api/races/:id/progress` | 上报观赛进度（秒），中断续看锚点，与结算无关 |
| `POST /api/races/:id/settle` | 按记录结算，幂等；只发一次奖；作废/越站记录返回 409；租约艇出赛时磨损与场次记入租约而非自有艇 |

## 数据表（SQLite）

`team` 车队资金/声望/积分 · `airships` 飞艇属性与部件健康 · `pilots` / `mechanics` 人员 · `upgrades` 改装件 · `circuits` 浮岛赛道 · `sponsors` 赞助商 · `rentals` 飞艇租约（艇型性能与费用快照、累计磨损/已用场次，active→returned 含结算退款）· `races` 比赛记录（分段过程/快照/奖励，running→settled，越站作废为 void；含观赛进度 watch_el 与作废时间 voided_at）· `race_log` 结算流水（经 `race_id` 关联到对应比赛）
